# LUFFI Miner Mini App

One Piece themed Telegram Mini App for mining **LUFFI** token on TON.

## Features (Demo)

- Tap to mine LUFFI
- Energy system with auto-regen
- Local balance storage
- Telegram WebApp integration
- One Piece / Luffy style design

## Deploy

This project is ready for Vercel.
